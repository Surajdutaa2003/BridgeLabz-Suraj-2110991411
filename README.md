# Design Principles Implementation

This repository contains implementations of various software design principles using JavaScript. Each file demonstrates a specific principle, providing an example for better understanding.

---

## Files and Principles:

### 1. `ISP.js`
- **Implemented By**: [Suraj]
- **Principle**: Interface Segregation Principle
- **Description**: Ensures that no class is forced to implement methods it does not use by breaking down large interfaces into smaller, more specific ones.

---

### 2. `LSP.js`
- **Implemented By**: [Suraj]
- **Principle**: Liskov Substitution Principle
- **Description**: Ensures that derived classes can be substituted for their base classes without altering the behavior of the program.

---

### 3. `SRP.js`
- **Implemented By**: [Suraj]
- **Principle**: Single Responsibility Principle
- **Description**: Each class or module should have one, and only one, reason to change, ensuring a single responsibility.

---

### 4. `dip.js`
- **Implemented By**: [Suraj]
- **Principle**: Dependency Inversion Principle
- **Description**: High-level modules should not depend on low-level modules. Both should depend on abstractions.

---

### 5. `dry.js`
- **Implemented By**: [Suraj]
- **Principle**: Don't Repeat Yourself (DRY)
- **Description**: Avoids code duplication by creating reusable functions, modules, or components.

---

### 6. `kiss.js`
- **Implemented By**: [Suraj]
- **Principle**: Keep It Simple and Stupid (KISS)
- **Description**: Encourages writing simple, clear, and concise code for better readability and maintainability.

---

### 7. `ocp.js`
- **Principle**: Open/Closed Principle
- **Description**: Ensures that software entities (classes, modules, functions) are open for extension but closed for modification.

---
